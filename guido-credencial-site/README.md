# Guido — sitio para GitHub Pages

El sitio está listo para subir a un repositorio de GitHub y activar GitHub Pages.

## Publicar

1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta, manteniendo `index.html`, `preview.webp` e `img/` juntos.
3. En **Settings → Pages**, elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Cuando GitHub muestre la URL pública, actualiza `og:image` y `twitter:image` en `index.html` para que apunten a la URL absoluta `https://.../preview.webp`. Los metadatos ya están incluidos; algunos sitios de mensajería requieren esa URL absoluta y pueden tardar en refrescar la vista previa.

**Privacidad:** este sitio incluye las imágenes del frente y dorso del DNI, que quedarán accesibles públicamente al publicarlo.
